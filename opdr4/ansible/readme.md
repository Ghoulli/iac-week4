Het verschil tussen Import en Include tasks zijn het volgende:
Import:
- Statisch
- Geen dynamische aanpassingen mogelijk
- Snel en eenvoudig

Include:
- Dynamisch, door o.a. variabels, loops en conditionals.
- Flexibel
- Iets langzamer

Roles zijn handig omdat het playbooks modular, reusable en overzichtelijk maken. Dit komt voornamelijk door een standaard mappenstructuur die voor iedereen hetzelfde is. Dit is ook meteen de best practice om dit te gebruiken. Ook kun je de Ansible Galaxy gebruiken.
